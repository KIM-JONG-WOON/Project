# 보고서 주석 검토 도구 기획서 (수정본 v2)

Oct 28, 2026 · @종운

## 개요

"Claude야, 보고서 만들어줘"로 만든 보고서(또는 기존 파일)에서, 더 채우거나 부족하거나 이상한 부분을 **일일이 타이핑하지 않고 선택해서** Claude에게 다시 물어보고 고치는 웹 도구다. 수정이 끝나면 마지막 쪽에서 보고서 파일(HWPX/PDF)로 내보내거나, 보고서를 대본 삼아 PPT를 만든다.

대상 환경: 윈도우·맥 PC의 웹 브라우저(마우스 사용 기준). 개발은 Claude Code + Claude API로 진행한다.

핵심 흐름:

1. 시작 화면에서 **기존 파일 불러오기**(1순위) 또는 **보고서 만들기**(2순위)를 고른다.
2. 보고서를 **한 쪽씩 슬라이드처럼** 넘겨 보며, 고칠 문장을 클릭하고 주석을 쓴다.
3. 주석을 다 쓰고 **Enter**를 누르면 그 쪽의 주석 전체가 Claude에게 전송된다.
4. Claude 답변을 원문에 반영하거나 직접 고친 뒤 확정(초록)한다. 마음에 안 들면 재요청한다.
5. 마지막 쪽에서 **일관성 검토 → 형식 선택 → 미리보기 → 저장**으로 내보낸다.

## 시작 화면

| 메뉴 | 내용 |
| --- | --- |
| 기존 파일 불러오기 (1순위) | HWPX, DOCX 지원. PDF는 글자 위주로 읽음(제목·표 구분이 부정확할 수 있음). `.hwp`는 한글에서 "HWPX로 저장" 후 올리도록 안내 |
| 보고서 만들기 (2순위) | 위에 **기본 프롬프트**, 아래에 **주제·방향 입력창**. 참고 자료(파일·붙여넣은 데이터)도 첨부 가능 |

**기본 프롬프트**

- 사용자가 고칠 수 있고, 고친 내용을 그대로 기억한다.
- 여러 개를 **탭**으로 저장해 두고 골라 쓸 수 있다(예: "주간 보고", "제안서", "결과 보고").

## 화면 구성

- 보고서는 **한 쪽씩** 보여주고 이전/다음으로 넘긴다.
- [주석] 버튼: 현재 쪽의 모든 주석을 모아 보여준다.
- 수정으로 글이 늘거나 줄어 문장이 다른 쪽으로 넘어가면, 그 문장의 상태·주석·이력도 함께 옮겨 간다.
- 상태는 글자색이 아니라 **배경색**으로 표시한다(보고서 글자 자체가 빨간색일 수 있으므로).

## 상태 체계

| 상태 | 화면 | 내보내기 |
| --- | --- | --- |
| 검정 | 바탕 없는 검정 글씨(최초 상태) | 가능 |
| 빨강·요청 중 | 빨강 바탕 + 바로 아래 주석창 | 불가 |
| 빨강·결과 도착 | 빨강 원문 → Claude 답변 → 빈 주석창 + ✔ 버튼 | 불가 |
| 빨강·데이터 필요 | 빨강 원문 + "그래프에 쓸 데이터를 주세요" 안내 | 불가 |
| 빨강·반영 불가 | 빨강 원문 + 불가 이유 | 불가 |
| 초록 | 초록 바탕(수정 완료) | 가능 |

**상태 전환**

| 현재 상태 | 동작 | 결과 |
| --- | --- | --- |
| 검정 | 문장 클릭 | 빨강·요청 중 (주석창 열림) |
| 빨강·요청 중 | 문장 다시 클릭(전송 전) | 검정으로 복귀, 주석 삭제 |
| 빨강·요청 중 | 주석 작성 후 Enter | 쪽 단위 전송 → 빨강·결과 도착 |
| 빨강·결과 도착 | **Claude 답변 클릭** | 답변이 원문 자리로 옮겨지며 초록 |
| 빨강·결과 도착 | 원문을 답변 보고 직접 고친 뒤 **✔ 클릭** | 고친 원문이 초록 |
| 빨강·결과 도착 | 빈 주석창에 재요청 작성 후 Enter | 재요청 (대상은 현재 원문) |
| 빨강·데이터 필요 | 주석창에 데이터 붙여넣기/파일 첨부 후 Enter | 재요청 |
| 빨강·반영 불가 | 주석 고쳐 Enter / [원문 유지] | 재요청 / 검정으로 복귀 |
| 초록 | 문장 클릭 | 빨강·요청 중 (검정과 같은 동작) |

**최종 글 기준은 항상 원문이다.** Claude 답변은 참고용이며, 클릭해서 원문으로 옮기거나 사람이 원문을 고쳐야 반영된다.

## 이력 (호버 창)

- 빨강·초록 문장에 마우스를 올리면 **요청·수정 이력**이 나온다.
- 회차별로 [내 주석 → Claude 답변 → 확정된 원문]을 보여준다.
- **3개까지 보이고, 그 이상은 스크롤**로 본다.
- 이력에서 원하는 버전을 고르면 원문이 그 버전으로 바뀌고 빨강이 된다. ✔를 누르면 초록이 된다(실수했을 때의 되돌리기도 이 기능으로 한다).
- 호버 창은 약 0.3초 뒤에 열리고, 창 안으로 마우스를 옮겨도 닫히지 않는다.

## 선택 방식

| 동작 | 결과 |
| --- | --- |
| 문장 클릭 | 그 문장 하나의 상태가 바뀐다 |
| 왼쪽 버튼 드래그 | 드래그 범위에 걸친 문장 전체가 선택되고 주석 하나를 함께 쓴다 |
| Shift + 드래그 | 그래프·표·그림 영역(점선 박스). 드래그를 시작한 문단 사이에 들어가고 주석이 생긴다 |

마우스를 누른 뒤 5px 이상 움직이면 드래그로 처리한다. 브라우저 기본 동작(더블클릭 단어 선택, Shift+클릭 범위 선택, 글자 드래그 선택)은 막는다.

**선택 단위 규칙**

- **줄 단위**: 머리말, 목차, 한 단어짜리 줄, 표어, 제목. 그 줄 전체가 선택된다.
- **문장 단위**: 나머지 본문. 마침표(.)·느낌표(!)·물음표(?)를 문장 끝으로 본다.
- 숫자 속 마침표("3.5%", "2026.10.20", "1. 항목")는 문장 끝이 아니다.
- 줄을 판별할 때 **줄 앞뒤 공백을 제거한 뒤** 판단한다. 빈 줄은 선택 대상이 아니다.
- 판별 순서: ① Claude가 만든 문서는 처음부터 요소 종류(제목/목차/본문 등)를 표시해서 받는다. ② 불러온 파일은 문서 스타일 정보(제목 스타일 등)로 판단한다. ③ 그래도 모르면 끝에 . ! ?가 없는 줄은 줄 단위로 처리한다.

**결과 문장 수**: 3문장을 요청했는데 2개나 5개가 돌아와도 괜찮다. 개수보다 결과 품질이 우선이다. 돌아온 결과는 하나의 묶음으로 관리하고 확정도 한 번에 한다.

## Claude 전송

- 주석을 쓰고 **Enter**를 누르면 **현재 쪽의 주석 전체**가 Claude에게 전송된다. 주석창에서 줄바꿈은 Shift+Enter로 한다.
- 보내는 것: 주석이 새로 쓰였거나 바뀐 빨강 요소만 보낸다. 결과를 받고 그대로 둔 빨강은 다시 보내지 않는다.
- 현재 쪽에 **주석이 빈 빨강·요청 중**이 있으면 전송을 막고 해당 위치를 알려준다.
- 전송 중에는 로딩을 표시하고 그 쪽의 편집을 잠근다.

**보내는 데이터**

- 문서 내용(구조화된 데이터)을 문맥으로 함께 보낸다. 검정·초록 요소는 "수정 금지"로 표시한다.
- 요청마다 고유 번호, 쪽 번호, 대상(문장 ID 또는 영역 위치), 주석, 첨부 데이터를 보낸다.

**첨부 데이터**: Claude 채팅창처럼 파일(엑셀, CSV, PDF, 이미지 등)과 붙여넣은 데이터를 모두 읽는다.

## Claude 처리 규칙

- 주석이 달린 부분만 수정한다. 검정·초록의 내용은 바꾸지 않는다(그래프가 들어가 위치가 밀리는 것은 허용).
- 요청 번호마다 "반영함", "반영 불가 + 이유", "데이터 필요" 중 하나로 답한다.
- **그래프에 쓸 데이터가 없으면 숫자를 지어내지 않고 "그래프에 쓸 데이터를 주세요"라고 답한다.**
- 그래프는 이미지가 아니라 차트 설정 데이터로 받아 화면에 그린다(이후 수정과 내보내기를 위해).

**결과 검증 (프로그램이 자동 수행)**

1. 보낸 요청 번호가 응답에 모두 있는지 확인한다. 빠진 번호만 다시 요청하고, 2회까지 해도 없으면 반영 불가로 처리한다.
2. 검정·초록 요소의 내용이 바뀌었으면 그 변경을 버린다.
3. 응답 형식은 JSON 스키마로 강제한다.

이 검증이 보장하는 것은 응답 형식과 수정 범위까지다. 수정 내용이 맞는지는 사람이 확인하고 확정한다.

## 파일 내보내기

- 내보내기 버튼은 **마지막 쪽에서만** 나타난다.
- **검정과 초록만 있을 때** 켜진다. 빨강이 남아 있으면 남은 개수를 보여주고 [다음 빨강으로 이동] 버튼을 띄운다.

**내보내기 순서**

1. **일관성 검토**: Claude가 문서 전체를 읽고 숫자·용어·날짜가 서로 맞지 않는 곳을 **목록으로 제안만** 한다. 사용자가 고른 항목은 빨강 요청이 되어 일반 수정 흐름을 탄다.
2. **형식 선택**: HWPX / PDF / **보고서로 PPT 만들기**
3. **미리보기**: 실제 파일 형태로 그린 화면에서 글꼴·줄바꿈·배치를 확인한다.
4. **저장**

**PPT 만들기**: 보고서가 PPT의 대본이 되고, PPT는 보고서를 기준으로 만든다.

## 기본 사항

- 작업 자동 저장 및 다시 열 때 복원
- API 키는 서버에 보관(브라우저에서 직접 호출하지 않음)
- 문장마다 고유 ID를 붙여 관리한다. 화면의 문장 나누기는 표시용이다.
- 상태 색은 설정값으로 분리한다(색약 모드 대비).
